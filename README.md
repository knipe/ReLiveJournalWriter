# ReLiveJournalWriter
A clean, local HTML journal editor styled in bright pink and white. It features classic early-2000s fields for Date, Time, Mood, Music, and a main text box, alongside buttons to save entries locally in the browser and export static HTML files (index and calendar) ready to upload to your online diary.
